# Requirements
1. The civ is saved and opened as `civbuilder_civ` by default unless user names it.
2. The mod goes into the local mods folder.
3. Civ Builder is WCAG 2.2 AA compliant.
4. ACCESSIBILITY.md will contain a checklist, when all items in that checklist are evaluated as true, Civ Builder is considered WCAG 2.2 AAA compliant.
5. Undo and redo always work (Ctrl+Z, Ctrl+Y).
6. A civ has at most 24 civ bonuses.
7. The mod is two folders, `<name>-data` and `<name>-ui`.
8. The mod replaces one civ of the game.
9. Build says what it could not build.
10. CRAP score for all code must be lower than 10.
11. DRY score for all code must be lower than 0.8.
12. Mutator must be run after every change.
